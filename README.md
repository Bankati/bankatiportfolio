# Portfolio — Mabibè Bankati

Portfolio personnel (Data Analyst / Data Scientiste), construit avec Next.js, TypeScript, Tailwind CSS et Framer Motion.

## Sections

- Accueil — présentation, stats
- Compétences — analyse de données, bases de données, IA, cloud & outils
- Portfolio — projets data (tableaux de bord, analyses)
- CV — formation, expérience professionnelle, certifications, compétitions
- Contact

## Démarrer en local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Build de production

```bash
npm run build
npm start
```
